
# Security Policy

## SENTINEL-X Security Policy

SENTINEL-X is an educational security monitoring
and threat detection project.

## Supported Versions

| Version | Support |
|---|---|
| 1.0.x | Current development version |

## Reporting Security Issues

If you identify a vulnerability, please report it
through the repository's private security reporting
channel where available.

Include:

- Vulnerability description.
- Steps to reproduce.
- Potential impact.
- Suggested mitigation.

Avoid publishing sensitive exploit details before
the issue has been investigated.

## Security Principles

1. No unauthorized system access.
2. No automatic execution of security actions.
3. Use synthetic logs for testing.
4. Validate inputs.
5. Protect sensitive log information.
6. Review and test detection rules.

## Responsible Use

SENTINEL-X is intended for authorized security
monitoring, defensive research and educational purposes.

## Disclaimer

This project is an experimental prototype.
Detection results may contain false positives or
miss suspicious activity.
